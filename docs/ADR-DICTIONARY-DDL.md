# 字典DDL导入：字面量与属性分离

修复可复现的数据错误：COMMENT中的NOT NULL/DEFAULT曾被当成列约束；ENUM字符串里的右括号被截断；科学计数法默认值被截成前缀；超出安全整数的默认值被悄悄舍入。红测试均保留验证。

改用有界词元和括号扫描，仅静态解析单条MySQL CREATE TABLE的列元数据，不连接或执行SQL。字符串、反引号标识符、普通注释与语法词元分离；支持字符串中的逗号/括号/分号、双写引号、相邻字符串拼接、常用反斜杠转义和指数数值。读取NOT NULL、COMMENT与字面DEFAULT时忽略引号/注释和嵌套表达式中的同名词。

非有限数或超出安全范围的整数默认值明确失败；函数/复合默认表达式不执行、不伪造值，转为“默认表达式未求值”备注并在导入确认前显示。原始表达式备注最多1000字符。TINYINT(1)仍采用既有布尔映射，不能无损映射的数值默认值也只作备注，不再错误转为false。

上限仍为1MiB输入，另明确20000词元、32层括号、1000列。拒绝多语句、未闭合引号/注释、可执行版本注释及优化器提示。保留预览→选择→保存流程，失败不修改已有字典。

这不是完整SQL语法/服务器语义验证器。表级键和约束不推导API必填规则；常见表选项不作为列导入；不计算表达式，不模拟数据库类型强制转换，也不支持所有SQL模式。字符串采用MySQL默认反斜杠行为，不支持NO_BACKSLASH_ESCAPES或ANSI_QUOTES模式切换；未知语法不能宣称完整兼容。
