# 复用可信引擎编译结果，不复用脚本状态

本地压力回归曾在旧、新运行器均出现初始化或总截止超时；不能用放宽预算解决，也不能把一次重跑通过当作唯一根因证明。

应用模块启动时校验固定QuickJS glue/WASM的SHA-256并编译一次不可变 WebAssembly.Module。该模块通过Node的结构化克隆传给worker，仅复用可信机器码。每次执行仍创建全新WebAssembly.Instance、线性内存、Emscripten实例、QuickJS runtime/context以及拒绝追踪器，不复用用户全局、Promise状态、变量、回调或VM堆。

worker继续检查当前glue/manifest与编译缓存标识一致，错配明确拒绝。默认直接调用trackedQuickJS()仍支持独立校验和实例化。引擎资产更新后须重启应用，不能混用新旧缓存。校验防意外错配，不对能够同时修改代码与manifest的主机攻击者作保护承诺。

编译发生在应用启动、接受脚本任务之前；没有移出用户脚本计算，也没有暂停/扩大任务时限。每个worker仍为2秒总截止、250ms用户活动预算、原bootstrap上限及16MiB内存，网络/定时器等配额不变。首次应用启动会承担引擎校验与编译成本，不声称端到端冷启动免费。

使用固定Emscripten产物已有instantiateWasm回调实例化已编译模块；不修改C补丁、FFI、WASM字节或引擎保护。红测试后验证同一编译代码创建两个完全隔离的实例（全局值和未处理拒绝不互见）、结构化克隆、错误hash拒绝、原拒绝追踪器清理和60次成功/失败/取消的worker生命周期。全量与三平台结果以对应提交为准，不将优化等同于所有超时根因已解决。
