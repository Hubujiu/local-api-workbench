# 有界脚本阶段执行基础

这是后续共享脚本的内部执行基础，不代表项目/目录共享脚本编辑器已经接通。

简单拼接源码或只await外层函数不足以保证前一作用域的HTTP回调和定时器已经完成。新的runScriptSequence逐阶段等待runScript的异步任务及线程退出，再把变量作用域、请求内局部变量和请求修改传给下一阶段；不通过Node对象向沙箱传权限。

## 固定契约

- 每阶段独立QuickJS上下文；只通过明确的apt/pm变量与请求状态共享，不共享词法声明。阶段名附在断言/子请求证据与日志中。
- 最多4阶段，源码合计100000字符。一个原有前置或后置阶段的所有子阶段共享250ms活动预算、2秒墙钟截止、10次HTTP、100次定时器、1000次Faker、10000个微任务、1000条断言、100条日志及1MiB UTF-8输出上限。并行HTTP最多4、活动定时器最多32，VM仍为16MiB。
- 子阶段只拿剩余预算，绝不因新VM重置配额。runScript内部参数只能降低既有上限；完成后返回的活动时间/计数由worker在VM外采集，脚本不能伪造。
- 失败断言终止后续阶段且保留结果；异常带阶段来源和既有网络证据。取消/错误仍等工作线程退出；网络权限与Cookie session只沿用调用者已有授权。
- 单个原有脚本入口的默认预算不变。尚未改变计划执行规则；计划仍只运行显式脚本，不因未来共享设置而隐式加入代码。

固定验收覆盖HTTP回调完成后跨阶段变量/局部值/请求传播、失败停止、活动/墙钟总预算、累计网络/定时器/Faker/断言/日志限制、降低微任务预算及拒绝扩大上限。所有原脚本回归继续运行。
