# 目录请求参数

官方范围依据：https://wiki.apipost.cn/docs/folder/setting 。本实现基于当前平面目录模型，不虚构原版嵌套继承优先级。

- 配置中的公共参数编辑器可切换整个项目/一个目录；Header、Query、Cookie、表单文本沿用原验证和限制。
- 明确优先级：项目 → 当前完整目录名 → 接口。Header名称忽略大小写。每层的禁用同名行屏蔽上层，接口保留自身重复行。只匹配精确目录名，不把A参数应用于A/Child或同级B。
- “继承项目及目录参数”关闭两层默认值；API自身设置保持。Body只有form-data/urlencoded合入文本。
- 目录重命名转移参数，删除移除参数，目标目录已有配置时拒绝覆盖。操作不改旧计划/用例冻结的值；新计划冻结当前合并结果。
- 最多100个目录，总计256KiB；每目录沿用每类100条/64KiB上限。拒绝原型特殊名称与未知配置。
- 全局认证/脚本及递归目录模型仍未实现；本项不宣称全部参数继承等价。

验收：三层优先级/禁用屏蔽/兄弟及后代隔离、无源对象修改、旧快照不漂移、原子重命名/删除、真实HTTP及浏览器切换作用域/保存/执行/重命名/删除。正常用户编辑不会触发自动发送。
