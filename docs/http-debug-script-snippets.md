# 普通 HTTP 调试：常用脚本

打开普通 HTTP 的前置或后置 JavaScript 编辑器，可展开或收起「常用脚本」。用鼠标或键盘选择一个片段，会在当前行后插入一条独立语句；有选区时，使用选区结束处所在行，不删除所选内容，也不拆开该行。可使用编辑器的撤销与重做。

编辑器不解析多行 JavaScript。若当前行位于跨行语句、模板字符串或注释中，请先把光标移到适合插入独立语句的位置。选择片段只更新脚本草稿，不发送请求、不执行脚本，也不会自动保存。

可用片段只包括设置当前请求变量、读取可用变量（当前请求优先，未设置时可回退到有效的环境或全局变量）、读取示例环境变量（不输出值），以及判断后置脚本视图中的响应状态是否为 200。不会建议实际环境变量名、查询凭据、持久写入或网络调用，也不复制 Apipost 的完整目录。GraphQL、导入的原生任务和其它协议编辑器不显示此栏。
