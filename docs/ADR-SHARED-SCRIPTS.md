# 共享脚本与显式计划隔离

官方功能范围来源：https://wiki.apipost.cn/docs/http/global-paras/ 、https://wiki.apipost.cn/docs/folder/setting 、https://wiki.apipost.cn/docs/http_debug/script/ 。官方脚本页面有顺序图，但当前未取得可验证图像；以下是本工具明确采用的契约，不宣称已核实原版所有排序细节。

## 作用域与执行

- 公共参数设置页按整个项目/精确目录编辑前置和后置JavaScript。新编辑内容默认不启用，勾选后保存生效；不会因为编辑或保存自动执行。
- 前置和后置各自按“项目 → 当前完整目录 → 接口”执行。目录不递归；接口可单独关闭两层共享脚本，保留自身脚本。取消继承也会停止已物化的共享阶段。
- 每阶段使用独立VM，前一阶段的Promise、HTTP回调与定时器完成并退出后再进入下一阶段。通过apt/pm变量、请求内变量与请求修改传递状态；不共享词法声明。
- 全部子阶段共享原单个前置/后置脚本的时限和配额，不能因分阶段重置；具体见ADR-SCRIPT-SEQUENCE。异常、未处理拒绝、失败断言停止后续阶段。记录包含来源作用域。
- 源码从不提前插值。只有脚本显式调用replaceIn等API才解析模板，后置脚本可读取刚提取的值。

## 计划与快照

- 调试、压测、授权MCP单接口执行使用当前共享设置；接口用例创建时冻结源代码快照。修改项目或目录设置不会悄悄改变旧用例。
- 执行计划不自动继承项目/目录脚本。由接口创建步骤仍清除接口前后置脚本和操作，也清除共享阶段；计划只执行其明确保存的代码。旧计划/用例在加载时视为已冻结。
- 明确提供在计划JSON中的阶段源码是显式步骤内容，不再自动查找项目共享代码。该能力不等同自动继承。
- 目录重命名转移脚本配置，删除移除，目标已有配置时原子拒绝；旧快照不变。
- cURL只导出静态请求，不执行接口或共享脚本。共享数据库操作和原版全部脚本SDK仍不支持。

## 验收

固定验收包含作用域顺序、异步回调完成后跨作用域使用变量/请求修改、后置字面模板不被提前替换、关闭继承、精确目录隔离、用例冻结/计划不隐式继承、输入边界与重命名/删除，以及浏览器编辑保存、真实子请求/主请求、后置结果与关闭继承。没有扩大网络权限或关闭TLS保护。
