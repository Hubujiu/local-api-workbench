# HTTP 调试：URL 中的查询

普通 HTTP 调试的 Query 页会在已有参数表上方单独显示可解析的 URL 查询。不解码或合并重名项：`a%2Bb`、`a+b`、不带等号的 `flag` 和 `empty=` 都保留原样。仅编辑这里某一项的编码值时，变化写入当前请求的 URL 草稿，其他查询项、顺序及 URL 片段不变；不发送请求，不自动保存。直接改 URL 可更新这个分组。

本页不解析环境变量、不把 URL 查询提升成参数表数据，也不改项目／文件夹的公共参数。「URL 空值等号」只改当前 URL 中值真正为空的项：混合或无等号时全部保留，已全部保留时全部省略。不改非空值、顺序、片段，或下方参数表自身的等号开关。可以按出现顺序停用单项（不按参数名合并）；停用项仍可查看，重新启用会按原位置恢复原编码。全选支持混合态，全部停用时保留地址片段且仍可恢复。使用普通项目保存和重开保留未启用状态。可无歧义显示的导入定义、SDK、快照及其他非普通定义在此只读；无法安全拆分的 URL 请直接编辑地址。不改动项目、cURL 或 OpenAPI 的既有保存／导出约束。

无效的百分号编码或未编码的查询分隔符不会写入 URL。可在当前字段修正，或按 Esc / 失焦恢复最近一次有效的 URL 值。已输入的值按其编码拼写使用，例如输入 `%2B` 表示编码后的加号。直接改写地址仍然可用，替换后不能重新应用旧地址的未启用项。项目完整备份包含可用的私有状态；查看[存储与隐私说明](literal-query-editor-storage.md)。
