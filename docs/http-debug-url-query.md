# HTTP 调试：URL 中的查询

普通 HTTP 调试的 Query 页会在已有参数表上方单独显示可解析的 URL 查询。不解码或合并重名项：`a%2Bb`、`a+b`、不带等号的 `flag` 和 `empty=` 都保留原样。仅编辑这里某一项的编码值时，变化写入当前请求的 URL 草稿，其他查询项、顺序及 URL 片段不变；不发送请求，不自动保存。直接改 URL 可更新这个分组。

本页不解析环境变量、不把 URL 查询提升成参数表数据，也不改项目／文件夹的公共参数。参数表的等号开关仍只对参数表生效；不支持在 URL 分组禁用一条或统一改写等号。可无歧义显示的导入定义、SDK、快照及其他非普通定义在此只读；无法安全拆分的 URL 请直接编辑地址。不改动项目、cURL 或 OpenAPI 的既有保存／导出约束。

无效的百分号编码或未编码的查询分隔符不会写入 URL。可在当前字段修正，或按 Esc / 失焦恢复最近一次有效的 URL 值。已输入的值按其编码拼写使用，例如输入 `%2B` 表示编码后的加号。
