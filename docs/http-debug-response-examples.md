# 普通 HTTP 调试：响应示例

「响应示例」与实时响应分开，未发送请求也可使用。「成功」和「失败」可作为未保存的预设，预设的正文只读。通过「编辑」确认预设的名称和状态码，或通过「新建期望」明确添加一个示例，才创建本地草稿。创建后可编辑和切换各示例；切换不会发送请求、开启 Mock 或自动保存。

调试页新建的示例显式使用 `text/plain`（即使输入看起来像 JSON）。已有普通 JSON 示例必须保留合法的 JSON，非法草稿会阻止项目保存，按 Esc 可恢复该示例上一次有效正文。切换到同一项目里的 Mock 或设计页不会丢失这个草稿；这些界面不能替换该示例，目录改名和项目切换或重新加载也需要先修正或撤回正文。从 Mock 页明确确认删除该示例时，其未完成草稿一并丢弃。这里只编辑正文、名称及数字状态码，不改变原媒体、响应头或 Mock 延迟。若项目本来就开启 Mock，显式保存示例后，Mock 仍按既有规则和示例顺序选取响应。

有来源绑定、旧导入字段、其它媒体或超过 256 KiB 的正文在这里只读，请使用原响应定义或已有 Mock 编辑入口。状态 100–199 只作为文档示例；204、205 和 304 的传输仍不含正文。此编辑器没有复制 Apipost 的导入、格式化、参数助手或删除入口。
