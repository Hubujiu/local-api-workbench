# Visual local schema references

Add a distinct local-reference editor for object Schema nodes, including existing reference nodes. The normal type/constraint editor continues to reject reference nodes instead of silently replacing their semantics. Reference editing changes only $ref; sibling constraints, descriptions, examples, required membership and unknown extensions remain unchanged. Clearing the field removes only $ref. The enclosing dialog remains a draft and Cancel does not modify the interface.

Accept only current-document JSON Pointer fragments, at most 4096 characters and 32 path segments. Decode URI and JSON Pointer escaping, reject invalid escapes/missing targets/prototype-sensitive segments, and verify that the destination is a real Schema position using the same position table as the importer and reference guard. Boolean Schema targets are valid; literal examples and schema maps themselves are not targets. No remote fetch, named anchor lookup, project-external model lookup or new network permission. Recursion can be represented, but finite example generation still follows the existing bounded sampler rules.

Acceptance: first-failing independent test, preserve source/siblings and typed false targets, clear refs, reject remote/missing/literal targets atomically, real browser error-then-correct flow, saved-store preservation and generated body through the referenced schema. Primary format reference: https://json-schema.org/understanding-json-schema/structuring . Complex composition remains in JSON editing; this is not a complete schema graph editor.
