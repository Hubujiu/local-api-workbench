# 文档中的参数、表单与字面响应

## 问题

离线文档之前直接输出 request.body，导致 form-data/urlencoded 的表单列表看起来是空正文；Markdown 还缺少已有 HTML 中的参数定义。停用行没有标识、false Schema 被替换为 {}，固定三反引号围栏也不能忠实表示含围栏的正文。

## 契约

- 应用内 API 文档预览与独立 HTML 共用定义渲染器；Markdown 输出同一组 Query/Path/Header、正文、非空或布尔请求 Schema、响应定义及响应示例信息。
- 表单逐项展示名称、值、类型/必填/Schema、启停状态和描述，保留顺序与重复项，不把停用项伪装成已启用。0、false、空值及多行文本不会被当作缺失。空表单明确标注“无表单项”。
- form-data 的 file 行仅展示文件名和待选择/内容不内嵌提示，不把上传数据当作文本示例。不会读取文件路径、运行脚本或为了生成文档请求端点。
- false/true Schema 显式保留。响应示例可展示 Header 与 Mock 延迟；延迟不是实际服务的时延承诺。
- 管理绑定的 OpenAPI 示例以当前请求示例列表为准，响应定义段不重复原始的旧内联 body。保留外部示例元数据但不获取；可从原具名描述读取说明。该只读文档投影不修改项目，也不替代 OpenAPI 导出的来源冲突校验。
- HTML 字面数据转义；Markdown 标题、字段等字面元数据转义，正文围栏按内容选择足够长的反引号或波浪线，空字符串与单个换行不混为一谈。接口/独立文档中有意编写的 Markdown 继续保持原语义，第三方 Markdown 查看器仍有自己的安全策略。
- 原有导出前敏感信息警告保留。这不是通用密钥脱敏器：文本参数、正文和响应可能含凭据，分享前仍应检查。

## 验证

固定回归先复现表单/Markdown 字段缺失和围栏截断，随后覆盖字面恶意标记、分隔符、多行、boolean Schema、当前绑定示例与外部元数据、空正文、共享预览及不修改原数据。浏览器经真实文件选择和表单编辑生成预览，实际下载 HTML/Markdown，检查上传字节没有内嵌；独立 HTML 打开后表格数据仍在，未产生远端资源请求，并保留截图。浏览器结果须以对应提交的 CI 为准；不将本模块称为全部文档功能或完整复刻。

## 窄窗口表格

参数表保留最小 720px 宽度及固定列比例，状态和表头不挤成单字列。超出卡片宽度时仅表格区域横向滚动，不撑开整页；区域具有键盘焦点、名称和可见焦点轮廓。应用预览与离线 HTML 采用相同布局，浏览器验收覆盖键盘横向滚动及 600px 导出窗口无整页横向溢出。
