# 脚本响应处理视图，不覆盖网络证据

## 来源和选择

官方 Offline2 2.0.0 安装包 resources/app/build/send.asar 的 index.js 静态片段提供 pm.response.setBody / setCode 和 originalText / originalJson / originalCode。只静态阅读，没有运行原版；来源渠道见 ORIGINAL-OFFLINE2-RESEARCH.md。这不是原版 GUI 或全 SDK 等价验证。

本工具独立实现有界处理视图。后置脚本可以加工文本和状态供后续脚本读取，但不得让服务器实际返回的 500 在历史、预设断言或最终成功判定中悄悄变成 200。脚本断言可以针对加工后的视图，已有声明式断言、提取规则和状态策略继续针对网络响应。实际网络状态/正文和单独的 scriptResponse 同时留在运行记录；调试页新增“脚本视图”，默认实时响应仍显示原文。

## 契约

- pm.response.setBody(value) 接受文本或可 JSON 序列化的值；false、0、null、空文本均有效。正文限 64 KiB UTF-8，拒绝无效 Unicode、undefined、函数、循环和不可序列化值。修改前正文原值限 512 KiB；原有 1 MiB 序列化输出总预算仍优先限制，不扩大容量。
- pm.response.setCode(code) 只接受 100–599 整数。这是脚本数据视图，不发送额外 HTTP，不改传输状态、Header、Cookie、耗时、大小或原始二进制。
- 两种已支持模式均可通过 apt.response 调用；legacy 的 json 属性同步更新，apipost8 和 pm 的 json() 保持方法。JSON/状态脚本断言读取当前处理视图。
- 每次成功修改后，originalText()/originalJson() 或 originalCode() 返回对应字段最近一次修改前的值；JSON 每次读取给出新副本，先前非 JSON 返回 null。未修改字段不凭空增加其 original 方法。原版静态片段的 originalCode 函数读取可变 code；本工具明确捕获修改前数值，不声称复现该片段的动态行为。
- 项目、目录和接口的有序后置阶段传递处理视图及原值读取状态。raw 保留阶段管线最初收到的响应。所有阶段共用既有 250 ms 活动/2秒总期限及配额，VM 的 16 MiB 内存和 512 KiB 栈不变。
- 无响应的前置阶段明确拒绝；校验失败不改变此前有效视图。任一阶段抛错都不提交整条后置管线的处理视图。原始请求已发生的网络/数据库副作用不因此回滚。
- VM 和宿主均验证传递的数据，只接受 body/status，拒绝伪造 Header 等字段。处理视图以转义纯文本展示，不执行 HTML 或加载其资源。

## 不涵盖

不提供子请求回调响应的修改、Header/Cookie 修改、任意 Buffer/二进制转换或对原始状态策略的覆盖；不将所有原版扩展声明为兼容。一般 JavaScript 自行改对象不等于通过这些显式方法提交视图。

## 固定验证

核心回归覆盖模式、typed/空值、连续修改前值、拷贝隔离、无响应拒绝、UTF-8 边界、非法值原子性、跨共享阶段及错误不提交。独立 HTTP 服务返回真实 500，调试 API、落盘历史和执行计划均保持原文及失败，同时保留加工后的 200/正文；预设提取仍读取原文。浏览器脚本经实际发送后分别读取原文和处理视图，确认状态标签、转义资源零请求并保存截图。浏览器证据须以对应提交的 CI 运行结果为准。
