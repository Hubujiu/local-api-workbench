# 目录服务绑定与快照

状态：本地实现与固定验收已通过，待完整 CI。以下是实现前确定的契约。

- 使用项目现有的平面目录名称，目录可绑定共享服务；相对路径请求在没有显式 serviceId 时继承当前目录的服务。
- 完整 HTTP(S) URL 或以 {{变量}} 开始的地址保持直连，不因目录配置改变而静默改发其他主机。显式 serviceId 优先且要求相对路径。
- 本版目录为平面模型，不宣称递归目录继承。
- 创建/新增计划步骤、接口用例时冻结实际 serviceId。以后调整目录绑定不改变旧快照；环境地址矩阵仍按执行环境解析。
- 旧计划/用例不会因为新目录绑定而获得隐式服务。删除被引用服务时明确执行失败，不静默切换。
- 目录重命名转移绑定，删除移除绑定；不允许悄悄覆盖已有同名目录的绑定。
- 固定验收：显式优先、相对继承、完整 URL 不改、快照冻结、删除服务报错、真实计划执行与 UI 保存/重读。
- 公开补充依据：https://wiki.apipost.cn/docs/http/environment-variables/ 。本工具平面目录及安全直连规则属于明确实现边界。
