# 项目全局 HTTP 参数与冻结执行

契约依据：官方说明 https://wiki.apipost.cn/docs/http/global-paras/ ，其 Body 全局参数仅用于 form-data/urlencoded。本次是明确子集，不宣称所有全局功能均已完成。

- 项目设置集中编辑 Header / Query / Cookie / 表单文本。每类最多 100 条，总计 64 KiB UTF-8；不接受文件、隐藏未知字段、重复名字或无效 Header/Cookie。只有 Header 名称忽略大小写，其余区分大小写。
- 默认继承；接口设计可关闭。接口同名参数行优先，包括禁用行（明确屏蔽默认值）；同名接口行重复保留。全局参数仅填补缺省，不修改原始接口，不覆盖原始 Body 类型。JSON/raw/binary/none 不合入表单。
- 前置脚本开始之前合入，随后使用现有变量、动态值、脚本、Cookie 和认证处理。全局参数不扩大脚本权限、不覆盖认证层现有规则。
- 调试、cURL、压测、MCP 单接口执行使用当前项目默认值。新计划/用例创建时冻结参数值模板；后续项目默认值变更不影响快照，模板中的环境变量仍按执行环境解析。旧计划/用例不因升级获得全局参数；快照不重复合并。
- 全局参数可能将凭据发送到项目中的多个目标站点，界面明确提醒；本地文件及导出仍可能包含明文，用户需检查。没有自动添加任何真实凭据。
- 目录参数扩展另见 ADR-FOLDER-PARAMETERS；全局认证、全局前后置操作仍不支持，不静默伪装成已经实现。

固定验收包括纯合并与不变性、禁用覆盖、大小写、边界验证、旧快照隔离、真实 HTTP 调试/计划/用例/cURL/压测，以及浏览器编辑保存、切换设置页、真实发送和关闭继承。源码与 CI 结果为实际验证依据。

首次集成 CI 16cf9c6 的 9/10 项通过，浏览器在此前 NTLM 场景失败，尚未走到新增全局参数场景。保留 trace 证据：上一请求已返回 HTTP 响应，但后续历史刷新仍重绘整个编辑器；下一次 URL 填写期间输入节点被替换，URL 仍指向前一认证 fixture。修复在请求完成重绘时保留正在编辑的输入、焦点、选区和滚动位置；新增可控制历史刷新返回时机的浏览器回归，要求焦点与全选状态保留，原 NTLM 同 socket 与响应断言不放宽。这不是 NTLM 协议修复，也不把重试通过当根因修复。
